# Scope

The Universal Device Management Interface (UDMI) Working Group will develop, maintain, and evolve a community specification and supporting open-source artifacts, including:

- Core Specification  
JSON schemas defining device models, telemetry, state, and command structures
Canonical interaction patterns for device lifecycle and management
Documentation supporting consistent implementation across vendors

- Reference Implementations & Tooling  
Validation and conformance tools (e.g., registrar, validator)  
Behavioral testing frameworks (e.g., sequencer, pubber)  
Developer utilities and SDKs (e.g., Java, Python libraries)  

- Runtime & Integration Components  
Reference services (e.g., UDMIS, butler, bridgehead)  
Integration patterns for cloud platforms and edge systems  
Example deployments demonstrating scalable architectures  

- Interoperability Alignment  
Mapping and integration with existing building protocols and models, including:  
ASHRAE BACnet (including emerging RDF representations)  
Semantic models such as Brick and RealEstateCore  
Coordination with broader C4SB efforts, including the Open Building Graph (OBG)
