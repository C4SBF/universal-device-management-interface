# Universal Device Management Interface Working Group

The Universal Device Management Interface (UDMI) Working Group operates under the Linux Foundation within the C4SB initiative to develop and maintain an open, community-driven specification and reference implementation for scalable device management in the built environment.

The working group enables interoperability across building systems by defining standardized device-management interactions, supporting secure, cloud-connected operations, and accelerating the adoption of AI and data-driven services.

## Governance

The working group operates under Linux Foundation open governance principles, including:

- Open participation and transparent decision-making
- Meritocratic contribution model
- Vendor-neutral collaboration
- IP and licensing aligned with Linux Foundation policies

Technical direction is guided by a Technical Steering Group (TSG) composed of active contributors and stakeholders.
